# Profil-Quiz

Ein kleines interaktives Quiz, das ich erstellt habe, um meine ersten Erfahrungen mit **HTML, CSS und JavaScript** zu sammeln und zu vertiefen.

## Über das Projekt

Das Quiz besteht aus verschiedenen Multiple-Choice-Fragen. Die Antworten werden ausgewertet und der Nutzer erhält am Ende eine Rückmeldung über sein Ergebnis.

Das Projekt dient vor allem dazu, grundlegende Kenntnisse in der Webentwicklung praktisch anzuwenden.

## Verwendete Technologien

- HTML5
- CSS3
- JavaScript

## Funktionen

- Multiple-Choice-Fragen
- Auswertung der Antworten
- Dynamische Anzeige der Fragen
- Anzeige des Ergebnisses

## Was ich dabei gelernt habe

- Aufbau von Webseiten mit HTML
- Gestaltung mit CSS
- Grundlagen von JavaScript
- Arbeiten mit Variablen und Funktionen
- Bedingungen und Logik
- Reaktion auf Benutzereingaben
- Zusammenspiel von HTML, CSS und JavaScript

## Starten

Das Projekt benötigt keine Installation.

Einfach die `index.html` im Browser öffnen.
